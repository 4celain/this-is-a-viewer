# Security Policy / 보안 정책

## English

Only the latest published version of This is a Viewer receives security
updates.

Please report a suspected security issue privately by emailing
[thisisapps.support@gmail.com](mailto:thisisapps.support@gmail.com) with
`[Security]` in the subject. Include the app version, macOS version, and the
minimum steps needed to reproduce the issue. Do not attach private images,
file names, local paths, credentials, or other sensitive data unless they are
essential and have been redacted.

Use [GitHub Issues](https://github.com/4celain/this-is-a-viewer/issues) for
ordinary, non-sensitive bugs. Please do not disclose a suspected vulnerability
in a public issue before it has been reviewed.

---

## 한국어

This is a Viewer는 현재 공개된 최신 버전에 보안 업데이트를 제공합니다.

보안 문제로 의심되는 내용은 제목에 `[Security]`를 넣어
[thisisapps.support@gmail.com](mailto:thisisapps.support@gmail.com)으로
비공개 제보해 주십시오. 앱 버전, macOS 버전과 문제를 재현하는 데 필요한
최소한의 순서를 적어 주십시오. 꼭 필요하고 민감한 내용을 가린 경우가
아니면 개인 이미지, 파일명, 로컬 경로, 인증 정보 또는 개인정보를
첨부하지 마십시오.

민감하지 않은 일반 버그는
[GitHub Issues](https://github.com/4celain/this-is-a-viewer/issues)에 제보할
수 있습니다. 검토되기 전에는 의심되는 취약점을 공개 이슈에 게시하지
마십시오.
