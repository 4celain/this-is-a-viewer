# This is a Viewer 0.1.0

## English

First public release.

- GIF, APNG, and animated WebP playback with frame navigation
- Folder, multi-file, and ZIP/CBZ browsing
- Resizable thumbnail sidebar with multiple column layouts
- A keyboard shortcut reference in Settings
- Single-page, two-page, webtoon, and slideshow views
- Zoom, rotation, Reveal in Finder, sharing, and image information
- Confirmed Trash actions designed to protect original files
- Korean, English, Japanese, Simplified Chinese, and Traditional Chinese

Requires an Apple Silicon Mac running macOS 14 or later.

The app contains no ads, accounts, analytics, or tracking, and never modifies
an original file unless the user explicitly requests it.
