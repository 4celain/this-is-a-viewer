<h1 align="center">This is a Viewer</h1>

<p align="center">
  <strong>A fast, native macOS viewer for images, animation and short local videos.</strong>
</p>

Open images, animation, local video, folders and ZIP/CBZ archives in one
focused macOS viewing workflow.

![This is a Viewer 0.2.2 with the folder navigator and thumbnail sidebar](assets/this-is-a-viewer-overview.png)

## Download

- **[Mac App Store](https://apps.apple.com/app/this-is-a-viewer/id6797867939?mt=12)**
- **[Direct download](https://github.com/4celain/this-is-a-viewer/releases/latest)**

The Mac App Store and Direct editions provide the same viewing features. The
Direct edition is distributed as a notarized DMG and uses Sparkle updates.

> [!IMPORTANT]
> The update signing information has changed, so version 0.2.2 must be
> installed manually once. Download the 0.2.2 DMG and install it over the
> existing app. Automatic updates will resume after that.

> [!NOTE]
> Requires an Apple Silicon Mac running macOS 14 Sonoma or later.

## Highlights

### Browse and organize

- Collapsible folder navigator with Favorites, Recents and lazy tree expansion
- Drag-to-reorder Favorites with `Command-Z` undo
- Direct opening by drag and drop, including folders, ZIP and CBZ archives
- Container-first natural sorting that keeps each folder or archive together
- Optional recursive browsing through descendant folders

### Images and animation

- JPEG, PNG/APNG, GIF, WebP, HEIC/HEIF, AVIF, TIFF, BMP, ICO and DDS
- Playback, pause and frame navigation for GIF, APNG and animated WebP
- Motion badges and optional duration labels in thumbnails
- Area selection and copy from a paused animation frame

### Local video

- MP4, M4V and MOV playback through macOS AVFoundation
- Looping playback, mute and volume control, scrubbing and 0.5×–2× speed
- One-second keyboard seeking and paused-frame area copy

### Reading and viewing

- Resizable thumbnail sidebar with configurable columns
- Single-page, two-page and webtoon layouts, plus slideshows
- Fit, zoom, rotation, flip and top-aligned viewing for tall images

### Safe local workflow

- Show in Finder, sharing, file-name and path copy, and image information
- Move to Trash confirmation and safeguards for archive contents and folders
- No ads, accounts, analytics or tracking; originals stay unchanged unless
  you explicitly request a file action
- English, Korean, Japanese, Simplified Chinese and Traditional Chinese, with
  VoiceOver support

### 주요 기능

#### 탐색과 정리

- 즐겨찾기·최근 항목과 필요한 항목만 펼치는 접이식 폴더 탐색기
- 드래그 즐겨찾기 순서 변경과 `Command-Z` 복귀
- 폴더·ZIP·CBZ 드래그 앤 드롭 열기
- 폴더·압축파일별 내부 순서를 유지하는 컨테이너 우선 자연 정렬
- 선택 가능한 하위 폴더 재귀 탐색

#### 이미지와 애니메이션

- JPEG, PNG/APNG, GIF, WebP, HEIC/HEIF, AVIF, TIFF, BMP, ICO, DDS
- GIF·APNG·animated WebP 재생, 일시정지와 프레임 이동
- 썸네일 모션 배지와 선택 가능한 재생 시간 표시
- 정지한 애니메이션 프레임의 영역 선택 복사

#### 로컬 영상

- macOS AVFoundation을 이용한 MP4·M4V·MOV 재생
- 반복 재생, 음소거와 음량 조절, 시간 탐색, 0.5×–2× 배속
- 키보드 1초 이동과 정지한 영상 프레임의 영역 선택 복사

#### 읽기와 보기

- 크기와 열 수를 조절할 수 있는 썸네일 사이드바
- 한 장·두 장·웹툰 보기와 슬라이드쇼
- 맞춤, 확대·축소, 회전·반전과 긴 이미지 최상단 시작

#### 안전한 로컬 작업

- Finder에서 보기, 공유, 파일명·경로 복사와 이미지 정보
- 휴지통 이동 확인과 압축파일 내부·폴더 원본 보호
- 광고·계정·분석·추적 없음. 명시적인 파일 동작 없이는 원본을 변경하지
  않음
- 한국어·영어·일본어·중국어 간체·번체와 VoiceOver
